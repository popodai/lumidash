# LumiDash

โปรแกรมแฟนเมดสำหรับเล่น Lumivara Online หลายบัญชี ไม่เป็นทางการ ไม่เกี่ยวข้องกับผู้พัฒนาเกม

ที่นี่มีไฟล์ติดตั้ง ไฟล์อัปเดต และคู่มือผู้เล่นของ LumiDash สำหรับ Windows

**อ่านก่อนติดตั้ง: [คู่มือผู้เล่น](./%E0%B8%AD%E0%B9%88%E0%B8%B2%E0%B8%99%E0%B8%81%E0%B9%88%E0%B8%AD%E0%B8%99%E0%B8%95%E0%B8%B4%E0%B8%94%E0%B8%95%E0%B8%B1%E0%B9%89%E0%B8%87.txt)** ติดตั้ง login หลายบัญชี ซ่อนเกม แจ้งเตือน เครื่องหน่วง และการอัปเดต

## ดาวน์โหลด

ไปที่ [Release ล่าสุด](https://github.com/popodai/lumidash/releases/latest) แล้วดาวน์โหลด `LumiDash-Setup-<เวอร์ชัน>.exe`
(ไม่ต้องโหลด `.blockmap` กับ `latest.yml` สองไฟล์นั้นโปรแกรมใช้อัปเดตตัวเอง · "อ่านก่อนติดตั้ง.txt (คู่มือผู้เล่น)" คือคู่มือเดียวกับข้างบน)

- Windows อาจขึ้น "Windows protected your PC" เพราะโปรแกรมยังไม่ได้เซ็นรับรอง: กด More info แล้วกด Run anyway
- Windows Security แจ้งเตือนไฟล์ `ffmpeg.dll` (Trojan:Win32/Posilod.EB!cl) หรือหน้าต่าง LumiDash ว่างเปล่า: เกิดกับเวอร์ชันก่อน 0.4.10 แก้โดยโหลดเวอร์ชันล่าสุดแล้วติดตั้งทับ (login และการตั้งค่าอยู่ครบ)
- ติดตั้งแล้ว LumiDash อัปเดตตัวเองเมื่อมีเวอร์ชันใหม่ (ถามก่อนทุกครั้ง)

มีปัญหาหรือสงสัย ถามคนที่ส่งโปรแกรมนี้ให้ ไม่ใช่ทีมงานเกม
