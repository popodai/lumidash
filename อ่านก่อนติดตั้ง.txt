LumiDash · คู่มือสั้นสำหรับผู้เล่น
==================================

LumiDash เป็นโปรแกรมแฟนเมดสำหรับเล่น Lumivara Online หลายบัญชี ไม่เป็นทางการ ไม่เกี่ยวข้องกับผู้พัฒนาเกม

  • เปิดเกมได้หลายบัญชีพร้อมกัน แต่ละบัญชีมีหน้าต่างและ login ของตัวเอง (เกินกว่า 3 บัญชีต้องมี Premium ตามกติกาของเกม ดูข้อ 3)
  • มี Dashboard รวมทุกบัญชีไว้ที่เดียว: HP/SP/EXP, EXP ต่อชั่วโมง, เวลาถึงเลเวลถัดไป, แผนที่, มอนรอบตัว, ปาร์ตี้, แชท, กระเป๋า
  • เด้งแจ้งเตือนเมื่อบัญชีไหนต้องการคนดู เช่น หลุด ตาย หรือ Auto Play หยุด
  • อ่านข้อมูลอย่างเดียว ไม่ได้กดหรือเล่นอะไรแทน (Auto Play เป็นระบบของเกมเอง)

มีปัญหาหรือสงสัย ถามคนที่ส่งโปรแกรมนี้ให้ ไม่ใช่ทีมงานเกม เพราะไม่ใช่โปรแกรมของเขา


1. ติดตั้ง
----------
  • ตัวล่าสุดดาวน์โหลดได้ที่ https://github.com/popodai/lumidash/releases/latest
    เอาไฟล์ "LumiDash-Setup-<เวอร์ชัน>.exe" ไฟล์เดียว ("latest.yml" โปรแกรมใช้อัปเดตตัวเอง ไม่ต้องโหลด)
  • ไม่ต้องลงโปรแกรมอื่นเพิ่ม ใช้ได้กับ Windows 10 หรือ Windows 11 แบบ 64 บิต ไม่ต้องใช้สิทธิ์ admin
    เกมทำงานบน Microsoft Edge WebView2 ของ Windows ซึ่ง Windows 11 มีอยู่แล้ว และ Windows 10 เกือบทุกเครื่องก็มี
    ถ้าเครื่องไหนยังไม่มี เปิด LumiDash ครั้งแรกจะถาม แล้วดาวน์โหลดจาก Microsoft และติดตั้งให้เอง (ต้องต่อเน็ต ใช้เวลาไม่กี่นาที)
  • ดับเบิลคลิกไฟล์ "LumiDash-Setup-….exe"
  • ถ้าเบราว์เซอร์เตือนตอนดาวน์โหลดว่าไฟล์นี้ไม่ค่อยมีคนโหลด ให้เลือกเก็บไฟล์ไว้ (Keep / Keep anyway)
  • Windows อาจขึ้นกรอบสีน้ำเงิน "Windows protected your PC" เพราะโปรแกรมยังไม่ได้เซ็นรับรอง (code signing)
    กด "More info" (ข้อมูลเพิ่มเติม) แล้วกดปุ่ม "Run anyway" ที่โผล่ขึ้นมา
  • กด Next ไปจนเสร็จ (ค่าที่ตั้งไว้ใช้ได้เลย ไม่ต้องใช้สิทธิ์ admin) จะได้ไอคอน LumiDash บน Desktop และใน Start menu


2. เปิดครั้งแรก และ login
-------------------------
  • เปิด LumiDash จะเจอ Dashboard กับการ์ด "บัญชี 1" กดปุ่ม "เปิด" ที่การ์ด หน้าต่างเกมจะขึ้นมา
  • login ในหน้าต่างเกมนั้น เหมือนเล่นบนเว็บ
  • login ด้วย Google ทำในเบราว์เซอร์ของเครื่อง เพราะ Google ไม่ให้ login ในโปรแกรมแบบนี้
      1) กด login ด้วย Google (Sign in with Google) ในหน้าต่างเกม เบราว์เซอร์จะเปิดหน้า "เข้าสู่ระบบ Lumivara Online ด้วย Google" ของ LumiDash
      2) ถ้าหน้าต่างของ Google ไม่เด้งขึ้น กดปุ่ม "เข้าสู่ระบบด้วย Google" บนหน้านั้น
      3) เลือกบัญชี Google ของไอดีนั้นให้ถูก
      4) เบราว์เซอร์ถามว่าจะเปิด LumiDash ไหม ให้กดเปิด แล้วหน้าต่างเกมจะเข้าเกมเอง
    ทำทีละบัญชี
  • login แล้ว LumiDash จำไว้ให้ ครั้งต่อไปกด "เปิด" ก็เข้าเกมได้เลย
  • อยากใช้ภาษาอังกฤษ: ปุ่ม "ตั้งค่า" มุมขวาบนของ Dashboard › ช่องแรก "ภาษา · Language" › English
    (English: Settings, top right of the Dashboard › first row "ภาษา · Language" › English)
  • LumiDash ตัวนี้เปิดเกมผ่านลิงก์ชวนเพื่อนของคนที่ส่งโปรแกรมให้ (เหมือนกดลิงก์ "ชวนเพื่อน" ของเกม)
    ถ้าเป็นไอดีใหม่ (เริ่มเล่นไม่เกิน 7 วัน) แล้วเติมเงินในเกมรวมครบ 600 บาท เกมให้ EXP Scroll x2 + Drop Scroll x2 กับคุณ
    และให้รางวัลกับคนที่ชวน · ไอดีที่เล่นมาเกิน 7 วัน หรือผูกโค้ดคนอื่นไว้แล้ว ไม่มีผลอะไร


3. หลายบัญชี
------------
  • กด "+ เพิ่ม" ใน Dashboard เพื่อเพิ่มบัญชี (ตั้งไว้ได้สูงสุด 10) แล้ว login ไอดีนั้นในหน้าต่างใหม่
  • อย่า login ไอดีเดียวกันในสองบัญชี
  • กติกาของเกม: 1 IP เล่นฟรีพร้อมกันได้ 3 ตัว เกิน 3 ตัวเมื่อไร ทุกตัวต้องมี Premium
    ไม่งั้นตัวที่ไม่มี Premium ไม่ได้ EXP และของดรอป และเทรด/ตลาด/ขายของให้ NPC ไม่ได้ (หรือเข้าเกมไม่ได้เลย)
    มือถือ เครื่องอื่น หรือเกมที่เปิดในเบราว์เซอร์ ที่ใช้เน็ตเดียวกันนับรวมด้วย
  • LumiDash เช็คกติกานี้ให้: จะเปิดบัญชีที่ 4 ขึ้นไปได้ เมื่อทุกบัญชีที่เปิดอยู่เข้าเกมแล้วและมี Premium
    ถ้ายังไม่ผ่าน จะขึ้นกล่องบอกว่าบัญชีไหนยังไม่มี Premium · บัญชีที่เข้าเกมโดยไม่มี Premium ตอนเปิดเกิน 3 จะเด้งเตือน
    และเตือนก่อน Premium ของตัวไหนหมด 30 นาที
    (LumiDash เห็นแค่บัญชีในโปรแกรม มือถือหรือเครื่องอื่นต้องนับเอง)
  • ชื่อหน้าต่างเกมบอกว่าเป็นบัญชีไหน เช่น "บัญชี 2 · ชื่อตัวละคร"


4. ซ่อนเกม กับ ปิดเกม (ไม่เหมือนกัน)
------------------------------------
  • ซ่อนเกม = เกมยังเล่นต่อ Auto Play ยังเดิน แค่หน้าต่างหายไป
      - กด "ซ่อนเกม" ข้างชื่อตัวละครใน Dashboard (ทีละบัญชี) แล้วกด "ไปที่เกม" เพื่อเรียกกลับ
      - หรือคลิกไอคอน LumiDash ที่มุมขวาล่างของจอ เพื่อซ่อน/แสดงทุกบัญชีพร้อมกัน
        (ถ้าไม่เห็นไอคอน กดลูกศร ^ ข้างนาฬิกา)
  • ปิดเกม = ตัวละครออกจากเกม Auto Play หยุด
      - ปุ่ม "ปิดเกม" ใน Dashboard (ถามก่อนปิด) หรือ X ของหน้าต่างเกม
      - บัญชียังอยู่ในรายการ กด "เปิด" ที่การ์ดเพื่อเข้าใหม่
  • ออกจากโปรแกรม: คลิกขวาที่ไอคอน LumiDash มุมขวาล่าง แล้วเลือก "ออกจากโปรแกรม"


5. แจ้งเตือน
------------
  • LumiDash เด้งแจ้งเตือนเมื่อ: หลุดแล้วไม่ต่อกลับเองใน 1 นาที, ตัวละครตาย,
    Auto Play น่าจะหยุด (ไม่ได้ตีและไม่ได้ใช้สกิลอะไรเลย 5 นาที), มีคนกระซิบ, มีคนชวนเข้าปาร์ตี้, ไอเทมที่เฝ้าไว้เหลือน้อย
  • ระหว่างที่ยังมีเรื่อง ไอคอนมุมขวาล่างจะมีจุดแดง คลิกแจ้งเตือนเพื่อไปที่หน้าต่างเกมของบัญชีนั้น
  • เฝ้ายาหรือไอเทม: Dashboard › แท็บ "กระเป๋า" › กดที่ไอเทม › ติ๊ก "เตือนเมื่อเหลือน้อยกว่า" แล้วใส่จำนวน
  • ยาที่ใช้ไป: แท็บ "กระเป๋า" บอกว่ายาแต่ละชนิดใช้กี่ขวดต่อชั่วโมง และจะหมดในอีกนานแค่ไหน เริ่มแสดงเมื่อเล่นครบ 5 นาที
  • แจ้งเตือนเข้า Telegram ด้วยก็ได้ (ไม่ใส่ก็ไม่เป็นไร เตือนที่ Windows เหมือนเดิม)
      1) ใน Telegram คุยกับ @BotFather พิมพ์ /newbot แล้วตั้งชื่อบอท จะได้ KEY (Bot Token)
      2) หน้าตั้งค่า › "แจ้งเตือนผ่าน Telegram" › วาง KEY แล้วกด "เชื่อมต่อ"
      3) กดปุ่ม "เปิดแชทกับบอท" แล้วกด START ใน Telegram (หรือส่งข้อความอะไรก็ได้) โปรแกรมจะเชื่อมต่อให้เอง และบอทจะส่งข้อความทักมา
    จากนั้นเรื่องที่เปิดไว้จะเด้งทั้ง Windows และ Telegram · ส่งเฉพาะตอนมีแจ้งเตือน จึงไม่ทำให้เกมช้า
    ข้อความแจ้งเตือน (ชื่อตัวละคร ข้อความกระซิบ) จะผ่านเซิร์ฟเวอร์ของ Telegram · อย่าบอก KEY กับใคร · ไม่ใช้แล้วกด "เลิกเชื่อมต่อ"
    ถ้าหน้าตั้งค่าบอกว่า "บัญชี Telegram ที่รับแจ้งเตือนบล็อกบอทนี้อยู่" (เช่น เผลอกดหยุดหรือบล็อกบอทตอนลบแชท):
      กด "เปิดแชทกับบอท" แล้วกด Restart หรือ Unblock ใน Telegram โปรแกรมจะเห็นเองแล้วกลับมาส่งต่อ ไม่ต้องใส่ KEY ใหม่
  • เปิด/ปิดทีละเรื่อง ตั้งจำนวนนาที และปุ่ม "ลองแจ้งเตือน" อยู่ในหน้าตั้งค่า (ปุ่ม "ตั้งค่า" มุมขวาบนของ Dashboard)
    ถ้ากดลองแล้วไม่ขึ้น ดูว่าไม่ได้เปิดโหมดห้ามรบกวน (Do not disturb) ของ Windows ไว้


6. เครื่องร้อนหรือหน่วง
-----------------------
  • เกมที่ซ่อนไว้ยังวาดภาพเหมือนเปิดบนจอ เปิด 3 บัญชีจึงเท่ากับเปิดเกม 3 จอ
    (ค่าเริ่มต้น) ทุกบัญชีเล่นเต็มที่เท่ากัน ไม่ว่าจะซ่อน ย่อ หรือโดนหน้าต่างอื่นบัง LumiDash ไม่ลดความเร็วจอไหน
  • ช่วยได้มากที่สุด: ในเกม เปิดหน้าต่างตั้งค่า ตรง "จอดำประหยัดแบต" เลือก "ไม่แตะ 1 นาที" ทีละบัญชี
    ไม่ได้แตะเกม 1 นาที เกมจะหยุดวาดภาพ แต่ Auto Play เดินต่อ และ Dashboard ยังเห็นครบ กลับเข้าเกมด้วยการเลื่อนปุ่ม
    ระหว่างนั้นหน้าเกมใช้ CPU เหลือราว 1 ใน 4 และ LumiDash ลดหน่วยความจำของหน้านั้นให้เอง
  • ในเกม ตั้ง "จำกัด FPS" เป็น 30 และ "คุณภาพภาพ" เป็นต่ำ ทีละบัญชี
  • Dashboard ไม่ต้องเปิดค้างไว้ก็ได้: ปิดแล้วเกมยังเล่นต่อ และแจ้งเตือนยังทำงาน
    เปิดกลับ: คลิกขวาไอคอน LumiDash มุมขวาล่าง › Dashboard (หรือ Ctrl+Shift+D ในหน้าต่างเกม)
  • โน้ตบุ๊กที่มีการ์ดจอแยก ถ้าเกมหน่วง: Settings ของ Windows › System › Display › Graphics
    › เพิ่ม msedgewebview2.exe (อยู่ที่ C:\Program Files (x86)\Microsoft\EdgeWebView\Application\<เลขเวอร์ชัน>) แล้วเลือก High performance
    ลื่นขึ้น แต่เครื่องร้อนและกินแบตขึ้น
  • หรือท้ายหน้าตั้งค่าของ LumiDash เปิด "ประหยัดเครื่องตอนมองไม่เห็นเกม" เกมที่มองไม่เห็นจะหยุดวาดภาพ แต่ Auto Play ยังเดิน


7. อัปเดต และถอนการติดตั้ง
--------------------------
  • LumiDash อัปเดตตัวเอง: ตรวจตอนเปิดโปรแกรมและทุก 15 นาที เมื่อมีเวอร์ชันใหม่ จะขึ้นหน้าต่างบอกว่ามีอะไรใหม่
    (ไม่แย่งคีย์บอร์ดจากเกม ปุ่มที่ทาสก์บาร์จะกะพริบ)
      - กด "อัปเดต" แล้ว LumiDash จะดาวน์โหลด ปิด ติดตั้ง และเปิดขึ้นมาใหม่เอง (ราว 1 นาที) บัญชีที่เปิดอยู่จะเปิดกลับมาให้
        ระหว่างนั้นตัวละครออกจากเกมชั่วครู่ ถ้ากำลังเล่นอยู่ กด "ยกเลิก" ไว้ก่อนก็ได้
      - กด "ยกเลิก" แล้ว อัปเดตรอไว้ที่ปุ่มสีทอง "อัปเดต <เวอร์ชัน>" มุมขวาบนของ Dashboard กดเมื่อพร้อม
      - ตรวจเองได้: คลิกขวาไอคอน LumiDash มุมขวาล่าง › "ตรวจหาอัปเดต" หรือที่หน้าตั้งค่า
  • ได้ไฟล์ติดตั้งเวอร์ชันใหม่มาเอง (หรือโหลดจาก https://github.com/popodai/lumidash/releases/latest) ติดตั้งทับได้เลย
    login และการตั้งค่าอยู่ครบ (ถ้า LumiDash เปิดอยู่ ตัวติดตั้งจะถามแล้วปิดให้)
  • อัปเดตจากรุ่นก่อน (0.4.x): login ทุกบัญชี การตั้งค่าเกม และ KEY Telegram ตามมาเอง ไม่ต้องตั้งใหม่ ส่วนไฟล์ขยะของรุ่นเก่าโปรแกรมลบให้เอง คืนพื้นที่หลายร้อย MB
    โปรแกรมตรวจลายเซ็นของอัปเดตก่อนติดตั้งทุกครั้ง ถ้าลายเซ็นไม่ตรงจะไม่ติดตั้ง
  • ถอนการติดตั้ง: Settings ของ Windows › Apps หา LumiDash แล้วกด Uninstall
    login และการตั้งค่ายังเก็บไว้ที่ %APPDATA%\LumiDash ถ้าจะลบหมด ลบโฟลเดอร์นี้ด้วย

  Ctrl+Shift+D   เปิด/ปิด Dashboard
  F11            เต็มจอ
  Ctrl+R         โหลดหน้าเกมใหม่ (ตอนเกมค้าง)
